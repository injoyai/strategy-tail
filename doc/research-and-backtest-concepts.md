# 因子研究与回测搭建：概念与关系

指标负责计算，因子用于研究，条件负责判断，策略组织交易，回测检验结果。统一术语见 [业务词汇表](../CONTEXT.md)。

## 1. 从指标到回测

| 概念 | 回答的问题 | 例子 |
| --- | --- | --- |
| 指标 | 当前状态是什么？ | 今日量比为 1.8 |
| 因子 | 这个特征与未来收益有什么关系？ | 用量比给股票排序，比较各组未来收益 |
| 条件 | 是否满足指定要求？ | 量比大于 1.5 |
| 交易信号 | 何时出现买卖意图？ | 某只股票今天满足买入规则 |
| 策略 | 按什么规则选择、买入和退出？ | 多个条件组合，并配置卖出与独立风控 |
| 回测 | 在指定范围和执行假设下，策略结果怎样？ | 模拟成交，计算扣费后的收益与回撤 |

指标和因子没有绝对的计算边界，区别主要在用途。量比用于描述成交量时是指标，用于研究未来收益或股票排序时也是因子。因子可以来自价量、财务、估值、公告等数据，不限于技术指标，也不保证有效。

一个常见流程是：

```text
当时可获得的数据 → 指标或特征计算 → 因子研究 → 形成条件 → 组合策略
                                                               ↓
                         评价与调整 ← 回测执行 ← 运行配置与交易约束
```

研究可以帮助形成条件，但不是搭建策略的强制前置步骤。已有交易想法时，也可以直接搭建并回测。

## 2. 两个功能为什么相似，又为什么都需要

| 功能 | 核心问题 | 主要产出 |
| --- | --- | --- |
| 因子研究 | 特征是否有区分度？哪个方向或区间表现更好？不同年份是否稳定？ | 相关性、分组收益、稳定性等证据，以及候选因子 |
| 回测搭建 | 用哪些条件买卖，条件怎样组合，怎样退出？ | 可运行的策略规则 |
| 回测运行 | 加入资金、仓位、费用及执行约束后，结果怎样？ | 成交记录、收益、回撤及其他绩效结果 |

因子研究保留数值差异，例如量比 1.2、1.8、3.0；条件把这些数值转成满足或不满足，例如量比大于 1.5。两者可以共享计算基础，各自的评价问题仍然不同。

## 3. 量比的完整例子

以下参数只用于解释概念，不是策略建议或项目默认值。

1. **计算**：今日成交量除以前 5 个交易日的平均成交量，得到量比 1.8，均量不含今日。
2. **研究**：按量比给当日股票分组，比较未来收益，观察不同区间与年份的表现。
3. **形成条件**：选择“量比大于 1.5”作为待验证条件，也可以继续增加上限或其他条件。
4. **组合策略**：将它与其他买入条件组合，并明确卖出和独立风控规则。
5. **产生信号**：某只股票在判断时点满足整组买入规则，产生买入意图。
6. **执行与评价**：回测结合股票范围、资金、仓位、费用和成交假设决定是否成交，再统计结果。

信号不等于成交。有买入信号时，可能已经达到持仓上限，或资金不足以买入一手。条件的信号次数不能直接当作实际成交次数。

## 4. 哪些条件能由因子表达

| 条件类型 | 与因子的关系 | 例子 |
| --- | --- | --- |
| 当前值阈值或区间 | 通常可以直接由因子加比较运算表达 | 量比大于 1.5、均线偏离率处于指定区间 |
| 连续天数或变化过程 | 可以数值化，但必须保留完整的历史判断含义 | MACD 连涨天数、连续站上均线 |
| 交叉、反转或回踩事件 | 需要比较多个时点或多项状态，不能只看当前指标值 | 今日 MACD 柱为正且昨日不为正 |
| 持仓风控 | 依赖买入价格、持仓时间等状态，不宜直接当作普通股票因子 | 买入后止损、持仓期限、追踪止损 |

即使将某个条件编码成 0/1 特征，也不代表它与连续因子具有相同的排序或研究信息。

判断两个条件是否等价，至少要核对公式、参数、窗口是否包含当日、数据不足的处理、比较边界和信号时点。例如 `> 1.5` 与 `≥ 1.5` 在恰好等于阈值时不同；“柱值为正”也不等于“今天刚由负转正”。

## 5. 策略规则与运行配置

策略描述买卖决策，运行配置描述本次实验的范围和执行设置。两者合起来才能解释回测结果。

| 内容 | 所属概念 |
| --- | --- |
| 买入条件及 AND／OR 组合 | 策略规则 |
| 卖出信号、止盈止损、持仓期限 | 策略规则 |
| 回测年份、股票样本 | 运行范围 |
| 初始资金、仓位预算、最大持仓数 | 资金与仓位设置 |
| 成交价格假设、日线／分钟线、佣金与滑点 | 执行假设与成本设置 |

这里是概念划分，不代表界面或存储必须把所有设置放在同一个位置。复现结果时应同时保留实际使用的规则、参数和运行设置；修改已保存策略，不应改变历史回测的策略快照。

### 底层因子与条件的拆分

底层数值实现见 [`market.go`](../strategies/factor/market.go) 与 [`technical.go`](../strategies/factor/technical.go)。这些类型实现 `core.Factor`，供已有条件使用；没有自动加入研究目录，也没有改变界面、组件 ID、参数或策略保存格式。

| 现有条件 | 底层数值来源 | 条件层保留的判断 |
| --- | --- | --- |
| 价格、流通市值、成交额、单日涨幅范围 | 行情原值因子 | 上下限及原来的不限语义 |
| 成交量放大、缩量、倍量 | 今日成交量、前 N 日均量 | 严格或包含边界的比较，均量不含今日 |
| 高于均线、均线多头排列、连续站上、回踩 | 均线因子 | 因子之间比较，以及连续窗口或回踩事件 |
| RSI 低于阈值、处于区间、拐头、超卖回升、超买 | 浮点 RSI 因子 | 阈值、前后两日比较与交叉判断 |
| RSI 恢复 | 整数 RSI 因子 | 原行情整数算法及阈值比较 |
| ATR 波动率范围、ATR 止损与止盈 | ATR 因子 | 除收盘价转百分数，或结合买入价判断退出 |
| 布林下轨、下轨加缩量或 RSI、ZScore 超卖与归零 | 布林下轨、ZScore 因子 | 单条件或多条件组合，零方差时不触发 |
| MACD 正负、连涨、金叉、反转及卖出信号 | 参数化原始 MACD 柱序列与 DIF 因子 | 连续天数、历史极值、交叉及买入后时点限制 |
| 实体阳线、实体阴线 | 实体占当日振幅的比例 | 阴阳方向、原阈值与免校验规则 |

拆分保留以下已有口径，避免“公式看起来相同”导致历史信号变化：

- 普通均线保留行情价格精度；布林与 ZScore 使用浮点均值和总体标准差。
- 浮点 RSI 与整数 RSI 分开；原始 MACD 柱不除收盘价，也不乘 2。研究用的 MACD 柱强度仍是柱值除以收盘价。
- “成交量放大”比较 `今日量 > 均量 × 倍数`，倍量条件按原规则先求比值；保留原来的浮点运算顺序与比较边界。
- 实体占振幅与研究中的“实体幅度”分母不同，不能互换。
- 各条件保留自己的预热期、缺省参数和股票/持仓状态约束；板块、基准、复杂形态及持仓风控仍保留相应业务判断，不强制转换成普通数值阈值。

[`condition_equivalence_test.go`](../internal/lab/condition_equivalence_test.go) 使用重构前固定的 73 个组件信号基线，覆盖缺省参数与目录默认参数、逐日数据前缀、不同板块代码、零量和平价窗口。它验证这些固定场景的行为等价，不代表已经覆盖全部参数组合或真实行情。

## 7. 评价结果时的边界

- **因子有效不等于策略赚钱**：排序或分组收益关系还要经过阈值选择、买卖规则和交易成本的检验。
- **分组收益不等于账户收益**：研究统计未必模拟统一资金、同时持仓和实际成交，不能直接当作可实现的资金曲线。
- **研究数据必须当时可见**：未来收益可用于事后评价，不能进入当时的买卖判断；财务等数据还要区分业务所属时间与实际可得时间。
- **反复调阈值不等于验证**：用同一段数据反复选择最优条件，不能据此认定未来也有效；需要区分形成想法的样本与检验想法的样本。
