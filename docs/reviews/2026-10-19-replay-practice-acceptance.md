## 1. 已修复问题

| 问题 | 具体影响与修复 | 证据 |
| --- | --- | --- |
| 首帧收益图空白 | 数据到达时监听器先于 DOM 更新执行，图表宿主尚不存在。改为 DOM 更新后初始化；图表组件缺失提供文字提示 | 浏览器修复前 `initialChart=false`、修复后为 true |
| 快速换股后一直加载 | 旧股票请求尚未完成时，残留的 loading 阻止新股票请求，旧响应又被丢弃。换股及变体切换重置所属加载状态；加载或错误期间禁止继续播放 | `replay_test.mjs` 的并发请求回归、浏览器延迟响应场景 |
| 隐藏页签仍播放 | 页签使用 v-show，没有卸载组件，原卸载钩子无法暂停。监听页签切换取消计时并暂停，tick 再检查当前页签 | 响应式状态测试及浏览器切页后等待检查 |
| 实际成交原因不可完整查看 | 通用目录说明优先于实例名，隐藏实际参数；持仓日详情也不展示此前成交原因。保留实例名与说明，并在个股历史成交中显示已发生原因 | 规则参数与持仓日详情渲染回归 |
| 回放缺快照或数据错配仍可读取 | 缺已成交股票行情时仍可发布可用报告；变体序号、日期数量／顺序错配也未拒绝。发布前检查必需行情，读取时验证身份与日期对应 | `review_acceptance_test.go` 的失败不发布与错配拒绝用例 |
| 出题重试不能恢复原任务 | 同请求在任务运行期间先被 Runner 锁拒绝；前端会丢弃请求编号。先检查已持久化请求及其参数，不依赖最新策略版本或任务锁恢复原会话 | 持有 Runner 锁时重放同一出题请求测试 |
| 旧重练请求产生新记录 | 原题只记录最近一次重练键；进行第二次重练后重放第一次请求会另建记录。按已保存子会话请求键查找，并校验来源身份 | `TestPracticeRetry` 的交错重练请求回归 |
| 练习旧响应覆盖切换或较新版本 | 切换题目时旧动作仍能结束新题加载；同题旧读取可覆盖较新 revision。动作和轮询绑定请求序号，应用状态时拒绝版本倒退 | `practice_ui_test.mjs` 的延迟动作与版本倒退回归 |
| 重练响应切走用户后来选择的题目 | 重练未返回时打开另一题，旧响应会强制切入重练记录。返回时校验请求上下文，已切题则只刷新历史；重试键绑定原题 | 延迟重练响应的会话切换回归 |
| 后台完成回调找不到页面组件 | Vue 循环内字符串 ref 实际为数组，而任务完成分支调用单个组件方法。组合研究和盘感共用函数 ref，保存明确的单组件引用 | 真实浏览器验证两者引用不是数组，完成钩子均为函数 |
| 练习图表返回后失效 | 复盘／练习切换及载入会话会重建 DOM，但实例仍绑定旧宿主。渲染前核对宿主并释放、重建旧实例 | 图表实例身份测试及真实浏览器复盘返回 |
| 最后一天的结束入口被禁用 | 服务端允许再次 next 以行情用尽结束，但按钮因 canNext=false 禁用。保留当日买卖，按钮改为明确的“行情用尽，结束本题” | 模板行为测试与浏览器末日买卖、结束流程 |
| 练习 MACD 与策略口径不同 | 新写整数 EMA 在第二根样本即为 0.159，而策略公共算法为 0.15954415954415957。改为复用 `util.MACDDIF`／`MACDHistogram`；MA 整数价格口径不变 | 逐日前缀与公共 MACD 算法比较；移除原来的整数 MACD 期待值，验证正式共用口径 |
| 练习异常可能泄露题目身份 | 出题捕获 panic 后重新抛出，全局任务错误会回显原始异常。改为日志保留详情，对外返回匿名错误，并持久化失败终态 | 带身份哨兵的 panic 回归，验证不再抛出或对外返回哨兵 |
| 回放键盘与收益语义不完整 | 持仓／成交只有行点击，没有原生按钮；摘要 b 样式覆盖收益颜色。加入原生 K 线按钮，修正摘要红涨绿跌及金额正负号；缩短窄屏图表标题 | 键盘浏览器检查、格式化断言及窄屏截图 |

另修正一处 Go 工具链兼容测试：路径规范化在 Go 1.25 返回 301，在 Go 1.27 返回 307。测试接受这两种规范化响应，同时新增精确 Location 检查及跟随目标必须为 404 的断言；编码穿越段的拒绝测试不变，没有放宽产品路径校验。

未修改受保护核心类型、生产依赖、真实行情、已保存策略或已有题目快照；旧题继续使用原指标快照，新题使用统一 MACD 算法。

## 3. 数据量探针


环境为上述 Go 1.25 容器。固定合成日线、恒真买入及持有策略；测量包含账户逐日计算、原因记录、收盘帧和快照写盘，不含生产策略的全部指标运算或真实 SQLite 行情读取。
