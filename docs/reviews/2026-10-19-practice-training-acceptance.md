## 容量基准

命令：`go test ./internal/lab -run '^$' -bench '^BenchmarkTrainingBankMillionQuestions$' -benchtime=1x -count=1`。

合成 1,000 股 × 每股 1,000 根行情、1,000 个信号，共 1,000,000 道机会。实际写出共享快照与全量信号索引，没有截断题数；本机一次结果：

| 指标 | 结果 |
| --- | --- |
| 建立/持久化夹具及验证合计 | 4.845 秒 |
| 文件占用 | 157.4 MiB |
| 分批 GC 后保留堆增长 | 0.3472 MiB |
| 复用题库开始一题训练 | 7.726 毫秒 |

该基准测量存储与抽题路径，不执行完整策略扫描；保留堆不是峰值内存。首次真实全市场扫描耗时、磁盘性能及更长单股行情会不同，不以本结果承诺全市场准备秒开。扫描有界并发、取消、失败覆盖、随机全量去重和无重扫复用另由功能测试验证。

## 边界

- 未部署、未推送远程；不代表线上已更新。
- 单 Lab 服务实例写入；不支持多个进程同时写同一训练根目录。
- 训练 JSON 随实际作答和动作回执增长，每次原子提交需要读写该训练记录；没有声称百万题全部作答后的状态写入仍为常数开销。
- 下载文本的统计/格式化已自动测试；浏览器下载权限/目标目录交互不作为自动化通过声明。
