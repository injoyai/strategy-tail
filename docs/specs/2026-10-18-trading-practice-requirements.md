# 策略选股与盘感练习需求

日期：2026-10-18（Asia/Shanghai）。
状态：首版业务范围已由用户确认并实现；验证结果及未覆盖范围见[审核验收报告](../reviews/2026-10-19-replay-practice-acceptance.md)。本文包含对已确认规则的必要边界定义，实施方案见[精简实施文档](../plans/2026-10-18-trading-practice.md)。

## 1. 目标与边界

用户手动选择策略，由系统随机提供一个历史买入机会。用户在不知道股票身份、真实日期和后续行情的情况下，自行决定是否入场、何时离场，并按交易日逐天推进，用于练习入场、等待和离场判断。

本功能称为“盘感练习”。与[回测回放](2026-10-18-backtest-replay-requirements.md)分别定义：回测回放观察策略已经执行的交易；盘感练习由用户决定交易，不更改回测结果。所选策略只提供出题所需的买入条件，不自动买卖，不提示或对比策略卖出信号，不执行所选策略的独立风控。

首版核心流程：

```text
选择已保存策略及历史范围 → 随机出题 → 等待／买入／跳过
→ 手动逐日推进 → 手动卖出 → 空仓继续观察 → 结束本题 → 复盘
```

## 2. 已确认规则

| 项目 | 首版行为 |
| --- | --- |
| 策略来源 | 用户手动选择一个已保存的自由搭建策略 |
| 出题单位 | 指定历史范围内，满足买入条件的“股票＋信号日期” |
| 随机方式 | 在符合条件的机会中随机抽取，不依据未来涨跌、策略最终收益或历史成交筛题 |
| 盲练 | 隐藏股票名称、代码和真实日期，用相对交易日展示 |
| 观察图表 | 日 K、成交量、MA5／10／20、MACD；初始展示信号日前约 120 个交易日背景 |
| 入场选择 | 可在信号日买入、等待后买入，或跳过本题 |
| 成交价格 | 当前已展示交易日的收盘价，不加滑点 |
| 资金 | 每题独立预算 2 万元，包含买入费用，按 100 股取整 |
| 费用 | 使用现有手续费模型，开题时冻结配置 |
| 交易限制 | 买入当天不能卖出；每题一次买入、一次全部卖出，不加减仓，不再次买入 |
| 日期推进 | 手动逐交易日推进，不自动播放；不能回到过去重新交易 |
| 卖出之后 | 仍可逐日观察后续走势，不立即结束或揭示股票身份 |
| 结束 | 主动结束、跳过或行情用尽后进入复盘；未平仓只估值，不虚构卖出 |
| 复盘对象 | 评价用户自己的入场、等待和卖点，不与自动策略卖点比较 |
| 保存 | 自动保存当前题目、推进位置与操作；刷新可继续；重练单独记录 |

## 3. 出题、历史范围与数据

用户选择策略和信号日期的历史范围后开始出题。股票范围沿用本地已有股票数据范围，排除指数；首版不新增股票池编辑或下载流程。

同一股票在不同日期满足买入条件，属于不同机会；连续命中的日期也分别计为机会。对所有合格机会等概率抽取，因此信号较多的股票自然有较多机会，不声称每只股票等概率。不得只从既有回测的实际买入记录抽题，以免引入资金与排序造成的筛选。

策略只在题目起点判定是否符合。用户等待后买入时，不要求该日仍满足初始策略；否则会限制自主入场判断。空买入条件不能出题；已保存但没有卖出规则的策略，只要买入条件有效即可用于练习。

历史范围限定信号起点，不限定后续持仓和观察期限。后续行情使用开题时本地已存在的完整日线，可跨越所选年份；仅到开题时确定的数据截止点，后续更新不会延长或改写这道题。历史背景不足 120 个交易日时按实际可用数量展示并提示，不补造行情；指标计算需使用可用的更早历史预热。

求值只能使用截至信号日的行情和该时点可见的其他研究数据。缺数据、版本不兼容、无有效买入条件、无匹配机会及出题取消须有明确状态，不以随机不符合条件的股票替代。披露数据覆盖及筛选失败情况；练习成绩不代表全市场无偏样本，外部数据自身的历史修订可见性限制仍需保留。

抽题不要求随后必须上涨、存在卖点、能买满预算或具有完整 20 日复盘行情。某题后续数据不足时如实提示，不能因此按结果重新抽题。

## 4. 观察与操作

### 4.1 时间与可见信息

信号日为相对第 0 日，之前的背景为负索引，之后依次为第 1、2……日。按该股票实际有效日 K 序列推进，无 K 线的日期不生成可成交帧；界面说明此口径，不把缺失日期补成新行情。

当前练习日期是已揭示行情的最晚日期。可以缩放或查看已经揭示的历史，但买卖只发生在当前练习日期，不能在浏览到的旧 K 线上交易。初始约120根背景仅控制视窗，不限制可浏览历史；缩小或平移可查看开题冻结快照中当前可见日之前的全部历史（2026-10-24补充）。真实日期不能出现在坐标轴、提示框、买卖标记、详情、URL 或练习响应中。

未结束前只下发已经揭示的行情和相应指标，不提前下发完整后续行情再由前端遮挡。任务进度、历史列表与错误提示也不得泄露本题股票身份、真实信号日期或未来结果。盲练是产品展示与数据访问契约，不承诺阻止用户在其他研究页面主动查询或凭走势认出股票。

初始图表没有未来卖点或完整收益。MACD 展示固定参数 12／26／9，柱值为 DIF−DEA，不乘 2；它不代表所选策略内所有 MACD 条件都采用相同参数。MA 与 MACD 不使用未来行情计算，不因可视窗口改变而重置历史预热。

### 4.2 未买入、持仓与已卖出

- 未买入：可买入、推进下一交易日、跳过或主动结束；跳过即结束本题，之后可查看复盘。
- 持仓中：可推进、在符合限制时全部卖出，或主动结束。不能再买入；买入当日卖出按钮给出明确限制。
- 已卖出：可继续逐日推进或结束，显示原卖点与固定的已实现收益；不能重新买入，也不直接展开未揭示走势。
- 已结束：不可再交易、推进练习日期或修改操作；可浏览已揭示过程、复盘和重练入口。

主动结束时仍有持仓，记录“未平仓”及结束日估值。推进到最后一根可用日 K 后仍允许在该日按规则作出买卖决定；明确提示已无后续行情。用户结束或再次请求推进时以“行情用尽”结束，不提前剥夺最后一天的决策机会。

买入预算不足一手（含费用）时，拒绝该次买入并显示原因，保留题目供继续观察或跳过。无效价格或损坏行情不能成交，不用上一收盘价伪造成当日成交价。

### 4.3 保存与恢复

每次推进、买入、卖出、跳过和结束都必须保存成功后才显示为已生效。保存失败保留上次成功状态，允许重试；断网或响应丢失时通过重新读取确认，不猜测是否成交。

重复点击、请求重试和多个页面操作不能重复成交或悄悄推进两天；过期页面收到冲突后重新读取最新状态，不自动重放旧决定。刷新、关闭页面和服务重启后可以恢复原题目、阶段、已揭示位置和操作。

策略库修改、费用配置修改或行情更新不能改写已开始的题目。重新练习同一道题时沿用其策略、行情和费用快照，建立新的练习记录并关联原题；已揭示过的题不能冒充首次盲练结果。首版保留历史记录及单题复盘，不增加跨题排行榜或绩效面板。

## 5. 成交与评价口径

每题预算独立，不把上一题盈亏滚入下一题。买入数量为含费总支出不超过 2 万元的最大 100 股整数倍；剩余现金保留。手续费沿用现有模型、冻结开题时费率，滑点设为零，不修改全局回测设置。首版不模拟涨跌停排队、成交容量和分钟内撮合，也不增加分红现金流。

| 数值 | 定义 |
| --- | --- |
| 买入总成本 | 收盘价 × 股数＋买入手续费 |
| 卖出净收入 | 收盘价 × 股数−卖出手续费 |
| 已实现净盈亏 | 卖出净收入−买入总成本 |
| 已实现净收益率 | 已实现净盈亏 ÷ 买入总成本 × 100% |
| 未平仓浮动盈亏 | 当前收盘价 × 股数−买入总成本，不预扣卖出费用 |
| 未平仓浮动收益率 | 未平仓浮动盈亏 ÷ 买入总成本 × 100% |
| 持有交易日数 | 卖出／结束日索引−买入日索引；买入日为 0 |
| 最大浮盈／最大浮亏 | 买入至卖出／结束之间逐日收盘浮动盈亏的正向最大值／负向最小值，同时展示收益率；无对应盈亏时为 0 |

最大浮盈／最大浮亏采用收盘口径，包含买入日与卖出／结束日的收盘估值，不用买入之前的盘中最高／最低价，不预扣尚未发生的卖出费用。已卖出后的涨跌不再改变持仓指标和已实现收益。

没有买入的题目标为“未交易”，收益率和持有天数不适用，不能当成一笔零收益成交；未平仓估值与已实现净收益分开，不混作完整成交。百分比分母无效或指标不足时显示不适用及原因，不输出无穷或伪造零值。

这是观察完整日 K 后按同日收盘价成交的练习假设，不等同于现有策略回测的全部执行规则，也不将练习成绩解释为可按相同价格实现的实盘收益。

## 6. 结束与复盘

结束后揭示股票名称（有可靠数据时）、代码和真实日期，展示初始信号、实际买卖点、等待过程、费用、净收益、持有交易日数和最大浮盈／最大浮亏。跳过、未买入结束、未平仓结束、实际卖出分别标注，不能相互冒充。

复盘包含结束时已经揭示的行情，并额外展示结束日之后最多 20 个可用交易日的走势。若卖出后已逐日观察很久，则保留这段完整过程；20 日是主动结束后额外展示的窗口，不是卖出后观察期限。后续不足时显示实际数量和数据截止日期，不重新拉取更新后的行情补齐。

复盘用于观察自己是否卖早、卖晚以及等待后的走势，不自动判定“卖出正确／错误”，不把事后最高点作为唯一标准。首版不自动生成策略卖出点、AI 评分或强制填写交易理由。

## 7. 界面与可用性

沿用 Lab 紧凑工具界面。策略与范围、当前相对交易日、阶段、主要操作及行情图优先进入首屏，历史与复盘按需查看。练习中不能与完整结果摘要混排导致泄露未来。页面名称仅出现一次，保留一个语义正确的 h1，不增加装饰横幅或重复标题。

红涨绿跌，收益有正负号和单位，不只依赖颜色。桌面及窄屏都能选择策略、逐日推进、买卖、结束、恢复和复盘；键盘可操作且焦点、禁用原因、加载、无数据、错误及重试状态明确。切换题目时不能混入旧响应、旧图或旧持仓。

## 8. 验收标准

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| P01 | 选择策略与出题 | 手动选择已保存策略；有效买入条件可单独出题，不强制配置卖出侧 |
| P02 | 随机与时点 | 抽取命中机会而非实际成交；追加／改变未来涨跌不改变同一历史时点的信号判断 |
| P03 | 盲练隔离 | 未结束响应、任务状态、列表、图表及提示均无股票身份、真实日期或未揭示行情 |
| P04 | 逐日与等待 | 第 0 日开始，可等待再买；一次推进一根有效日 K，浏览历史不能回到过去成交 |
| P05 | 资金与买卖 | 覆盖含费预算取整、预算不足一手、同日禁止卖出、一次全买全卖、不加滑点 |
| P06 | 卖后观察 | 卖出不结束、不揭示身份；仍可逐日推进，已实现收益与交易记录不再变化 |
| P07 | 结束边界 | 跳过／主动结束可复盘；最后一根 K 线仍可决策；未平仓只估值，无虚构卖点或卖出费用 |
| P08 | 复盘窗口 | 揭示身份与真实日期；结束后额外最多 20 日，不截掉卖后已观察的更长过程；不足明确披露 |
| P09 | 评价口径 | 净收益、收盘浮盈亏及交易日数可用固定案例核对；未交易和未平仓不冒充完整成交 |
| P10 | 保存与重试 | 刷新及重启可恢复；重复请求不重复执行；多页面冲突不覆盖较新状态；保存失败不宣称成功 |
| P11 | 快照与重练 | 更新策略、费用或行情不改旧题；重练另建记录，保留首次结果及关联关系 |
| P12 | 数据与界面 | 无匹配、缺数、损坏、取消、加载失败可辨识；窄屏及键盘可用，无重复标题或页面溢出 |

## 9. 首版不包含

多股账户与跨题复利、加减仓及反复交易、自动播放、实盘下单、分钟级交易、策略卖出对照、自动止损止盈、排行榜或自动判分、新行情源、生产依赖及回测引擎重构。已有回测回放、报告、CSV／HTML 与选股服务保持原有契约。

## 10. 连续练习与出题反馈（2026-10-19 用户补充）

已结束题目在练习和复盘视图均提供“开始下一题”，沿用本题策略与年份范围，使用策略当前保存版本重新随机出题。新题使用新的独立会话，原题仍保留在历史；同题重练继续使用原策略、行情和费用快照。新题提交期间避免重复创建，读取／提交失败保留原题并显示重试提示，策略已删除时引导重新选择。

出题等待时显示所选策略、年份、实际扫描数量及阶段，支持停止、刷新状态和返回出题页（后台继续）。加载和保存阶段没有可度量总量时使用不定进度，不提供估算的剩余时间。并行执行不得改变全范围命中等概率抽题规则，也不得泄露股票身份与真实样本日期。

## 11. 结束后的单题分析报告（2026-10-19 用户补充）

结束操作成功后自动显示本题报告，包含净盈亏、交易收益率、整题资金回报、实际费用、现金／持仓市值／总资金、等待及持有天数、最大收盘浮盈／浮亏，以及整题资金最大回撤和逐日资金明细。可切换 K 线复盘并下载文本版报告；既有已结束记录可直接生成，无需重练。

收益与费用沿用 §5；交易收益率分母为含费买入总成本，整题回报分母为预算。未交易的成交类指标不适用；未平仓只按结束日收盘估值且不预扣未发生的卖出费用。资金回撤以信号日至结束日每日总资金与初始预算为准，包含已发生费用。报告不使用结束后的额外复盘行情，不新增自动判分或事后最优买卖结论。
