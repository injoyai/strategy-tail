# 题库、训练与训练报告需求

日期：2026-10-19（Asia/Shanghai）。
状态：用户已确认；实现与验证记录见[实现约定](../plans/2026-10-19-practice-training.md)及[验收记录](../reviews/2026-10-19-practice-training-acceptance.md)。本文件定义需求口径。

## 1. 范围与优先级

正式报告针对一次训练：从用户开始练习到结束训练，汇总其中所有正式作答。结束一道题不等于结束训练，单题复盘不替代训练报告。

本文件取代[原盘感需求](2026-10-18-trading-practice-requirements.md) §10 中“下一题使用策略最新版本重新独立抽题”、§11 中“仅以单题报告收口”的目标。原需求的盲练、成交、费用、T+1、逐日观察、快照隔离及单题复盘规则继续适用；词汇见根目录 [CONTEXT.md](../../CONTEXT.md)。

## 2. 业务关系

- 一个题库包含至少一道练习题，可以用于多次训练。
- 一道题由股票、信号日期及固定的行情和规则确定；同股不同信号日期仍是不同题。
- 一次训练使用一个题库，独立保存开始、进度、结束状态及正式作答结果。
- 同题重练单独标记和记录，不混入正式训练成绩。
- 不同训练分别出报告，不按时间相邻或相同策略将记录自动拼接。

## 3. 题库建立与复用

用户选择策略与年份范围，首次扫描实际可读取、成功求值的数据，收集全部匹配机会建立题库。没有命中时明确失败，不生成可用空题库。首次准备后持久保留，后续训练复用，不为每一道下一题重新扫描全市场。

题库固定策略与行情快照。策略或行情更新后如需使用新数据，应另建题库，不改写旧库、旧训练及旧报告。不能在下一题时悄悄替换成策略最新版本。每题预算、费用冻结及实际成交口径继续沿用已有单题规则。

题库没有约定的固定题数上限；不能以任意截断或提前命中来冒充全部匹配。扫描失败、缺失数据、成功覆盖及数据截止信息继续诚实披露，完整匹配仅指成功求值的数据范围。

首次扫描可能较慢，需要真实阶段、完成数量和停止反馈；总量未知的加载／保存阶段不估算百分比或剩余时间。复用速度与大题库容量必须另行验证，不把现有小样本扫描基准当作全量性能结论。

## 4. 一次训练的生命周期

1. 从可用题库开始新训练，生成独立训练记录。
2. 随机抽题，同一次正式训练内不重复；各题继续使用原盲练与人工买卖流程。
3. 结束本题后，可以查看单题复盘或开始下一题；下一题仍属于当前训练。
4. 用户可随时结束训练；题库最后一道题完成后自动结束训练。
5. 刷新、切页或关闭页面不结束训练。进度持久保存，下次可恢复；恢复不能重复创建题目或推进交易日。
6. 结束训练时保留各题结果，冻结本次报告范围，不因后续重练、策略／行情更新而改变成绩。

训练内题目仍分别使用独立的 2 万元预算，上一题盈亏不带入下一题，不构造跨题复利账户。当前题持仓时结束训练，按当前已揭示日收盘价估值，标为未平仓；不虚构卖出，不预扣尚未发生的卖出费用。没有买入则归为未交易。

重复点击下一题或结束训练必须幂等；旧页面及晚到响应不能覆盖较新进度。失败保留已保存结果并允许核实、重试，不把未保存的动作展示为成功。

## 5. 训练报告口径

报告范围为该次训练中的正式作答。未抽取的题库题目、其他训练、同题重练及旧历史单题不进入本次统计。正式报告在训练结束后生成，支持重新查看和下载；单题复盘保留为钻取入口。

| 项目 | 口径 |
| --- | --- |
| 练习题数 | 本次训练实际进入练习的正式题目数，不是题库总题数 |
| 已平仓题数 | 发生真实买入与真实卖出的题目数 |
| 未交易题数 | 跳过或结束时没有买入的题目数 |
| 未平仓题数 | 发生买入但未真实卖出的题目数 |
| 盈利／亏损／打平题数 | 按已平仓题含费净盈亏的正、负、零分类 |
| 胜率 | 盈利已平仓题数 ÷ 全部已平仓题数；打平题计入分母 |
| 合计已实现净盈亏 | 各已平仓题的净卖出收入减含费买入总成本，再求和 |
| 平均交易收益率 | 各已平仓题净盈亏 ÷ 各自含费买入总成本，逐题算百分比后取算术平均 |
| 未平仓估值及浮动盈亏 | 按各自结束时已揭示收盘价计算，与已实现净盈亏分开展示 |
| 实际手续费 | 汇总正式作答实际发生的费用，标明包含未平仓题已发生的买入费用 |
| 逐题结果 | 题目结果分类、实际收支、收益率、持仓天数和单题复盘入口 |

没有已平仓题时，胜率和平均交易收益率显示“不适用”，不能显示伪造的 0%。没有买入的题目不当成零收益成交；未平仓题不进入胜率和已平仓收益统计。已实现净盈亏已经扣除费用，不再次扣除手续费合计。

训练中各题是独立资金假设，不把收益率相加称为总收益率，不生成伪造的连续账户复利或账户回撤。已有单题收盘浮盈亏与资金回撤可保留在单题详情，结束后的额外复盘行情不能计入成绩。

例如练了 5 题：2 题盈利、1 题亏损、1 题未交易、1 题未平仓。报告显示练习 5 题、已平仓 3 题、未交易 1 题、未平仓 1 题，胜率为 2÷3，即 66.67%；已实现净盈亏与平均交易收益率只统计已平仓的 3 题。

已平仓交易的胜率与平均收益率复用 `core.Stats` 的现有口径；调用前必须分流未交易与未平仓结果，不能用虚拟卖出凑入统计。本需求不新增跨题排行榜、自动评分或事后最优买卖结论。

## 6. 旧记录及界面

旧记录没有题库／训练归属和可靠的跨题边界，保留为“历史单题”，继续可查看和复盘，不删除、不强制改写、不猜测合并。旧题的创建／更新时间不能冒充整次训练的起止时间或实际操作耗时。

界面明确区分题库、训练和当前题目。保留“结束本题／下一题”和“结束训练”两个层级；单题结束不自动以单题报告代替训练结算。训练历史与报告能识别所属题库和这一次训练，重练有明确标识。

沿用简洁工具布局、原生操作、现有主题和红涨绿跌。桌面主要操作及摘要优先进入首屏，窄屏及展开明细保留必要滚动；不得靠隐藏内容或滚动条掩盖溢出。进行中题目及未开始题目仍不暴露股票身份、真实日期与未来走势；已结束题目的单题复盘继续遵守原可见范围。

## 7. 实现差距及验收标准

定稿时源码只有逐题会话与单个抽中候选，没有可复用的完整命中清单、训练归属和正式训练结束事件。因此不能仅把“单题报告”改名为“训练报告”来宣称完成。

验收要求如下；实际执行证据与限制另见验收记录：

| 场景 | 通过标准 |
| --- | --- |
| 同库多次训练 | 生成不同训练记录及各自报告，结果互不混入 |
| 建库后下一题 | 使用固定题库，不再全市场重新筛选，不切换策略版本 |
| 随机与去重 | 一次训练内题目不重复，未做题仍可随机抽取 |
| 单题库 | 完成唯一一道题后自动结束训练并生成一题报告 |
| 提前结束 | 已完成题保留，当前未交易／未平仓如实分类 |
| 中断恢复 | 刷新、关页、重启服务后可恢复已保存训练，动作不重复 |
| 五题分类案例 | 已平仓 3、未交易 1、未平仓 1，2 胜时胜率 66.67% |
| 打平及无成交 | 打平计分母；没有已平仓题时比率不适用 |
| 重练隔离 | 重练结果单独保存，不改变原正式成绩 |
| 费用与估值 | 只计真实费用，浮动与已实现分开，无虚构卖出或重复扣费 |
| 数据更新隔离 | 新策略／新行情不改旧库、旧训练及旧报告 |
| 旧记录兼容 | 保留历史单题，不按时间相邻自动合并 |
| 报告一致性 | 页面、下载及重读使用相同统计范围和口径 |
| 大题库与失败 | 真实规模验证有界内存、取消、覆盖披露和复用耗时，不静默截断 |
