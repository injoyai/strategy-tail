# 均线回踩 + 地量反转策略设计

> 日期：2026-07-04
> 类型：趋势回调买入 + 高胜率短线策略
> 持仓周期：2-5 天
> 止盈止损：固定比例

---

## 1. 策略概述

### 1.1 核心理念

在强势多头趋势中，等待股价回踩 MA5 短期均线，当缩量到极致且收盘收回均线之上时买入，2-5 天内以固定比例止盈止损。

### 1.2 逻辑链

```
强趋势（多头排列+均线向上）
  → 回踩MA5（不破MA10）
  → 地量缩量（卖压衰竭）
  → 收回均线（确认反弹）
  → +5%止盈 / -3%止损 / 5天强制平仓
```

### 1.3 高胜率依据

| 层级 | 信号 | 为什么有效 |
|------|------|-----------|
| 趋势过滤 | MA 多头排列 + MA20 向上 | 只在强势股操作，避开熊股 |
| 回踩识别 | 回踩 MA5 不破 MA10 | A股最经典短线支撑位，散户资金密集 |
| 量能确认 | 地量缩量 | 成交量无法造假，缩量=卖压枯竭 |
| 入场确认 | 收盘收回均线 | 避免接飞刀，确认反弹动作 |
| 出场纪律 | 固定比例止盈止损 | 消除情绪干扰，短线快速落袋 |

## 2. 买入条件设计

### 2.1 第 1 层：基础过滤（复用现有组件）

| 条件 | 组件 | 参数 | 说明 |
|------|------|------|------|
| 流通市值 | `A流通市值{Min: 50}` | ≥50 亿 | 排除小盘股流动性风险，不设上限 |
| 价格上限 | `A现价{Max: 200}` | ≤200 元 | 排除高价股，一手资金占用可控 |
| 过滤涨停 | `A过滤涨停{}` | 涨停不买 | 回测真实性保证 |

### 2.2 第 2 层：强趋势确认

| 条件 | 组件 | 参数 | 说明 |
|------|------|------|------|
| MA 多头排列 | **新增 `A均线多头排列`** | RequireAboveDays: 5 | MA5>MA10>MA20，收盘价在 MA20 上方≥5天 |
| MA20 向上 | `MAUp{Period: 20, Lookback: 3, MinSlope: 0.0003}` | 连续3天向上 | 确保中期趋势方向明确 |

**新增组件 `A均线多头排列`**：

```go
// A均线多头排列 判断 MA5>MA10>MA20（可选 MA60）的多头排列形态。
// RequireMA60 表示是否要求 MA60 也参与多头排列，默认 false。
// RequireAboveDays 表示收盘价需在 MA20 上方运行的连续天数，默认 5。
// 触发条件：
//   1. MA5 > MA10 > MA20（若 RequireMA60=true 则还需 MA20 > MA60）
//   2. 最近 RequireAboveDays 天收盘价均大于当天的 MA20
type A均线多头排列 struct {
    RequireMA60      bool
    RequireAboveDays int
}
```

### 2.3 第 3 层：回踩 MA5（新增组件）

**新增组件 `A回踩N日均线`**：

```go
// A回踩N日均线 判断股价回踩指定均线后收回的形态。
// Period 表示回踩的均线周期，默认 5（MA5）。
// SupportPeriod 表示下方支撑均线周期，默认 10（MA10），0 表示不校验支撑。
// MinTouchDays 表示近几天内至少有 1 天最低价触及/跌破 MA(Period)，默认 3。
// 触发条件：
//   1. 近 MinTouchDays 天内，至少有 1 天最低价 ≤ MA(Period)（触及或跌破均线）
//   2. 若 SupportPeriod > 0：回踩期间（近 MinTouchDays 天）最低价不跌破 MA(SupportPeriod)
//   3. 最新收盘价 > MA(Period)（收回均线，确认反弹）
type A回踩N日均线 struct {
    Period        int
    SupportPeriod int
    MinTouchDays  int
}
```

### 2.4 第 4 层：地量缩量确认（复用现有组件）

| 条件 | 组件 | 参数 | 说明 |
|------|------|------|------|
| 缩量 | `VolumeShrink{Days: 5, Ratio: 0.7}` | 今日量 < 5日均量 70% | 卖压衰竭信号 |

### 2.5 完整买入组合

```go
A均线回踩地量Buyer = buy.And{
    // 第1层：基础过滤
    buy.A流通市值{Min: 50},
    buy.A现价{Max: 200},
    buy.A过滤涨停{},

    // 第2层：强趋势
    buy.A均线多头排列{RequireAboveDays: 5},
    buy.MAUp{Period: 20, Lookback: 3, MinSlope: 0.0003},

    // 第3层：回踩MA5
    buy.A回踩N日均线{Period: 5, SupportPeriod: 10, MinTouchDays: 3},

    // 第4层：地量缩量
    buy.VolumeShrink{Days: 5, Ratio: 0.7},
}
```

## 3. 卖出条件设计

### 3.1 卖出条件 1：固定止盈止损（复用 `SellTPSL`）

```go
sell.SellTPSL{TakeProfit: 0.05, StopLoss: 0.03}
// +5% 止盈 / -3% 止损
```

逻辑：每日用收盘价相对买入价计算收益率，达到 +5% 或 -3% 触发卖出。

### 3.2 卖出条件 2：时间止损（新增 `A持仓N天`）

```go
// A持仓N天 买入后满 N 个交易日强制卖出。
// Days 表示持仓天数上限，默认 5。
// 触发条件：当前交易日距买入日达到 Days 个交易日。
type A持仓N天 struct {
    Days int
}
```

逻辑：通过 `dks` 的日期与 `buy.Time` 比较，计算已持仓天数。达到上限强制平仓。

### 3.3 完整卖出组合

```go
A均线回踩地量Seller = sell.Or{
    sell.SellTPSL{TakeProfit: 0.05, StopLoss: 0.03},  // 止盈5% / 止损3%
    sell.A持仓N天{Days: 5},                              // 5天强制平仓
}
```

### 3.4 卖出执行细节

回测引擎（`core/backtest.go`）已内置以下处理，直接复用：
- 滑点：单边 0.01 元/股
- 手续费：买卖双向
- 印花税：仅卖出
- 分钟级精度：提供分钟数据时，在分钟K线上精确判断触发点
- 虚拟成交：回测期末未卖出的持仓按最后日收盘价生成 Virtual=true 成交单

### 5.3 实现中发现的 Bug

1. **`SellTPSL` 历史数据误触发**：原有 `SellTPSL` 遍历了 `dks` 全部K线（含买入日之前的历史数据），导致买入当天就因历史价格触及止盈/止损线而卖出。新增 `A止盈止损` 只从买入日之后开始判断。
2. **`A持仓N天` 计算偏差**：原实现 `holdingDays` 包含买入日，导致 Days=5 时实际只持仓4天就触发。修复为不含买入日。

### 6.3 策略评估

**优势**：
- 2025年实现正收益（+13.36%），盈亏比1.10
- 2026年盈亏比1.21，接近盈亏平衡
- 亏损年份年化仅-3%~-7%，风险可控
- 交易频率低（年均80次），适合手工操作
- 信号精准，每次买入都是回踩后反弹第一天

**劣势**：
- 整体胜率35-46%，未达到预期的65%+目标
- 2022-2024年仍亏损（熊市/震荡市表现不佳）
- 盈亏比在熊市偏低（0.52-0.68）

**后续优化方向**：
1. 加入大盘指数过滤（如沪指在MA20上方才操作），规避系统性风险
2. 测试不同止盈止损比例（如止盈3%/止损2%）
3. 加入RSI/KDJ等动量指标作为额外确认
4. 测试回踩MA10而非MA5（更深的回踩，更大的反弹空间）
5. 按行业/板块过滤，聚焦强势板块
