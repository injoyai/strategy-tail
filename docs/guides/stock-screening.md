# Lab 选股策略

从左侧打开「选股策略」。可同时启用多套策略，扫描结果按股票代码去重，每行列出全部命中策略。表格支持按策略查看和分页。

## 配置和执行

- 内置规则来自原 Screen 的「MACD精选」「MACD基础(测试)」「布林+RSI(测试)」「MACD精选2」。内置规则默认关闭，可分别启用。对应买入逻辑与标签由两个入口共用。
- 「新建策略」可组合价格、市值、均线、成交量、MACD、RSI 和 Lab 现有因子条件。支持嵌套的「全部满足（AND）」和「任一满足（OR）」。可从已保存的回测策略复制买入树，随后独立编辑。条件和参数通过搭建器的目录与校验执行。
- 启用后立即扫描。Lab 启动时会重新扫描已启用策略。盘中按根配置的 `screen.interval` 刷新（默认 1 分钟）。盘后检查上证指数当日日线入库时间，日线到达后刷新一次。可用「立即选股」手动扫描。
- 配置保存在 Lab 工作目录的 `data/lab/screen.json`，部署容器使用已挂载的 `data/`。配置带修订号，旧版本保存返回冲突。扫描中修改配置时，当前扫描完成后执行最新配置。最近结果保留在服务内存中。
- 独立 `go run ./cmd/screen` 仍提供历史买卖点、卖点监控和个股诊断。Lab 选股页展示候选信号，使用自己的配置文件。

## 行情口径

股票池取自 MySQL 证券目录，目录没有股票时使用库中已有日线的股票集合。评估使用当天已入库的分钟聚合线，收盘后优先用同日已入库的官方日线。个股缺少当天行情或前置日线时跳过。读取失败的股票计入覆盖统计。股票价格对应结果行的行情时间，盘中可因分钟入库时间不同而有差异。

内置策略复用原 Screen 最多 300 根历史日线的窗口。自定义策略最多使用最近六年的 1,200 根日线，因子回看参数上限为 1,000。指标所需历史不足时按现有规则处理。

## 接口

| 方法和路径 | 用途 |
| --- | --- |
| `GET /api/screen` | 读取策略配置、运行状态及最近结果 |
| `PUT /api/screen` | 提交读取到的 `version` 和完整 `strategies` 列表 |
| `POST /api/screen/run` | 手动启动一次后台扫描，已有扫描时返回 409 |

策略项包含 `id`、`name`、`enabled`。自定义策略另带 `buy` 条件树，新建时由服务生成 ID。策略条件可使用 `GET /api/builder/components` 和 `GET /api/factors` 提供的目录。
