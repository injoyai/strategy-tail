# Lab 选股策略

从左侧打开「选股策略」。可同时启用多套策略，扫描结果按股票代码去重，每行列出全部命中策略。表格支持按策略查看和分页。

## 配置和执行

- 点击顶部「策略列表」展开开关。内置规则来自原 Screen 的「MACD精选」「MACD基础(测试)」「布林+RSI(测试)」「MACD精选2」。内置规则默认关闭，可分别启用。对应买入逻辑与标签由两个入口共用。
- 「新建策略」可组合价格、市值、均线、成交量、MACD、RSI 和 Lab 现有因子条件。支持嵌套的「全部满足（AND）」和「任一满足（OR）」。可选配卖出树与独立风控，也可从已保存的回测策略复制买入、卖出和风控条件。使用回测搭建器的共用条件编辑器和目录。
- 启用后立即扫描。Lab 启动时刷新当日买点预览，历史成交直接从账本读取。盘中按根配置的 `screen.interval` 刷新（默认 1 分钟）。盘后检查上证指数当日日线入库时间，日线到达后刷新一次。可用「立即选股」手动扫描。
- 配置保存在 Lab 工作目录的 `data/lab/screen.json`，部署容器使用已挂载的 `data/`。配置带修订号，旧版本保存返回冲突。扫描中修改配置时，当前扫描完成后执行最新配置。最近一次当日扫描结果保留在服务内存中。
- 选股通过 Lab 运行。原 Screen 的 `data/database/trade.db` 可在「历史买卖」中作为只读档案查看。

## 行情口径

股票池取自 MySQL 证券目录，目录没有股票时使用库中已有日线的股票集合。评估使用当天已入库的分钟聚合线，收盘后优先用同日已入库的官方日线。个股缺少当天行情或前置日线时跳过。读取失败的股票计入覆盖统计。股票价格对应结果行的行情时间，盘中可因分钟入库时间不同而有差异。

内置策略复用原 Screen 最多 300 根历史日线的窗口。自定义策略最多使用最近六年的 1,200 根日线，因子回看参数上限为 1,000。指标所需历史不足时按现有规则处理。

## 本地交易与盘中提醒

- 收盘以北京时间 15:00 为买点时刻。Lab 在收盘分钟线可用后，用 TDX 实时报价初筛，并用股票和基准的当日收盘分钟核验。按「策略 ID、股票代码、买入交易日」将买点写入 `data/lab/screen-trades.db`。服务须在收盘至 15:20 的确认窗口内运行。该窗口内会重试未完成的确认，同日重试保留首次写入的记录。
- 待卖出的交易保留入库时的自定义卖出条件和风控。停用策略会停止新增买点，已有交易仍跟踪卖点。Lab 在盘中按 `screen.interval` 只检查尚未完成且早于当天买入的交易。读取 TDX 当日分钟线，并在内存中结合 MySQL 历史日线。当天缺少可用分钟时继续等待。
- 第一次命中卖出条件时，更新原交易的卖出时间、价格和完成状态，并在同一事务写入提醒事件。已完成交易从待卖出查询排除，历史重算优先展示本地交易记录。Lab 打开时通过 WebSocket 显示提醒，可点击查看共用 K 线诊断。
- TDX 行情只用于当日计算。SQLite 保存策略交易、事件和最近回算状态，MySQL 行情保持只读。「当日卖点」和「历史买卖」读取同一本交易账本。

## 当日卖点、历史买卖与 K 线

- 当日买点展示最新扫描命中。Lab 历史补算只由「重算历史」触发，按当前启用策略回看最近 `screen.lookback` 个交易日（默认 60 日），用已入库日线补齐缺失的 15:00 买点。待卖出交易使用买入时保存的卖出条件和风控回算。
- 重算与实时跟踪写入同一个本地 `data/lab/screen-trades.db`。按策略 ID、股票代码和买入交易日去重，保留已入库的买入信息和已确认卖点。重算补齐的卖点更新原交易，无需发送盘中提醒。切页、刷新和服务重启后均可读取。
- 「重算历史」和「立即选股」使用右下角全局任务栏。准备后显示已处理股数和总数，切页仍可查看。可通过「停止任务」取消，保留最近一次完整结果。
- 停留在选股页时，自动预览扫描也在同一任务栏显示。正在运行的手动批量任务优先显示。
- 每笔历史买点独立跟踪其策略首次卖点，按上海交易日执行 T+1。回算卖点使用已入库的历史分钟线和同一卖出逻辑。遇到缺失分钟线的交易日且尚未确认卖点时，保留交易并显示「待核对」。无卖出条件的自定义策略保留买点。
- 历史可按策略、买入日期、持有／已卖出、股票或标签筛选。胜率、盈亏比和平均持有天数按筛选范围内已卖出记录计算，收益使用信号价格，未扣交易成本。
- 原 Screen 的旧 SQLite 作为只读档案显示在历史表中。重合记录以当前账本为准。
- 点击买点、卖点或历史中的股票，或输入代码点击「查看K线」。诊断使用项目统一 KLineChart 与估值组件，显示日线、成交量、MACD、买卖标记和策略逐项判断。

## 接口

| 方法和路径 | 用途 |
| --- | --- |
| `GET /api/screen` | 读取策略配置、运行状态及最近结果 |
| `PUT /api/screen` | 提交读取到的 `version` 和完整 `strategies` 列表 |
| `POST /api/screen/run` | 手动启动扫描，已有扫描或全局批量任务时返回 409 |
| `GET /api/screen/history` | 查询账本交易和原 Screen 历史，`mode=sell` 查询账本中当日已入库卖点 |
| `POST /api/screen/history` | 补齐账本买卖点，已有全局批量任务时返回 409 |
| `GET /api/status`、`POST /api/stop` | 查看或停止当前手动选股或历史回算任务 |
| `GET /api/screen/events?after={id}` | WebSocket 推送已提交的当日卖点，按事件 ID 续读 |
| `GET /api/screen/diagnose/{code}` | 查询个股日K、信号标记和策略诊断 |

策略项包含 `id`、`name`、`enabled`。自定义策略另带 `buy` 条件树及可选的 `sellSignal`、`risks`，新建时由服务生成 ID。策略条件可使用 `GET /api/builder/components` 和 `GET /api/factors` 提供的目录。
