# K 线股票估值信息

Lab 的交易明细与已结束练习的 K 线复盘在图表上方同时对比历史与最新本地估值。历史默认取买入日／信号日，可选择已收盘的历史日期，并恢复默认日；历史数据缺失时不以最新快照回填。逐日回放只显示截至当前回放日收盘时已可得的记录。盲练阶段不提供股票身份、估值或相关请求。统计、成交与图表原始数据不变。

| 字段 | 展示单位 | 数据集 |
|---|---|---|
| PE（TTM）、PE（静态） | 倍；负值标为亏损 | `tdx.valuation.daily` 或 `valuation.daily` |
| 股息率 | %，沿用通达信供应商口径 | `tdx.valuation.daily` |
| PB（MRQ） | 倍 | `valuation.daily` |
| 总市值、流通市值 | 亿元，原数据为人民币元 | `valuation.daily` |

缺失值显示「—」，零股息率显示 `0.00%`。日期与来源常驻展示，不同来源可能具有不同日期。同一字段取当前查询时点可用且业务日期最新的值，同日期优先通达信；不根据股价估算缺失的 PE、股息率或市值。

## 数据与读取接口

`GET /api/stock-info/{code}` 读取已有本地 `ResearchData`，不启动行情初始化、联网采集或同步任务。代码为 `sh/sz/bj` 加六位数字。返回 `code/asOf/metrics`；每项含 `key/value`，有值时含 `date/source/availableAt/pitStatus`。`value:null` 表示无记录或字段缺失。

可选 `asOf` 为带时区的 RFC3339 时间，不能晚于当前时间。逐日回放使用 `YYYY-MM-DDT15:00:00+08:00`，按 `EventAt` 和 `AvailableAt` 双重截断；历史无记录时显示空态，不能以今天的快照回填。通达信快照以实际采集时间作为可得时间；东方财富历史修订记录未经验证，该限制保留在响应和界面口径中。

数据采集沿用既有行情更新及估值同步流程。缺少历史记录不等于公司指标为零。信息栏的最新快照可能晚于图中交易日，只作当前资料展示；不参与历史回测、统计或练习结算。已生成独立 HTML 与 screen 诊断不增加隐式 Lab 接口依赖。

共享界面所有者为 `js/components/StockInfo.js`。`historyDate/historyLabel` 开启历史／最新对比并指定默认日；`asOf` 则用于回放的纯历史模式，不请求最新数据。两列各自保留来源日期、错误与空值，任一列失败不清空另一列。加载、错误、重试与行情绘制独立，换股／换日期清除旧值并忽略旧响应；卸载后响应失效。
