# 行情源时间与策略口径

应用从外部项目维护的 [MySQL 数据源](mysql-storage.md) 读取日线和分钟线。日线 `time` 是行情源日期，分钟线 `time` 是行情源日期和时分。中国标准市场按 `Asia/Shanghai` 解释源时间，策略日线使用同日 15:00，分钟线保留原有时分。

价格与成交额以原币种浮点值保存，A 股单位为元。MySQL 股票成交量以股保存，策略层按整数手使用。指数保留数据源的成交量单位。未知成交额在 MySQL 中使用 `NULL`，进入现有策略模型时以零表示。日线查询保留真实的上一条收盘价。

股本来自同一库的 `gbbq` 事件。每根日线使用当日已生效的股本，换手率按成交股数除以流通股本计算。缺少相应事件时，股本和换手率保持缺省。
