# 行情源时间与数据层

行情拉取和新库存储沿用 tdx v2 的源时间契约，不增加时区字段或 Unix 时间戳：日线为 `YYYY-MM-DD`，分钟线为 `YYYY-MM-DD HH:MM`。日线日期是源标签，不在库中补造收盘时刻。行情源时间不按主机 `TZ` 或证券所在地重新解释。

## 目录与旧数据

`pull.database` 仍是数据根目录。新记录写入其下的 `source/`，使用 SDK `SQLiteStore`：

```text
data/database/
  day-kline/                         # 旧日线，只读
  min-kline/                         # 旧分钟线，只读
  source/
    .time-format                     # SDK source-time-v1 标记
    updated.db                       # 更新/覆盖状态，独立于行情时间
    cn/stock/day/sh600000.db          # KlineDay，Time 为源日期
    cn/stock/min/sh600000/
      sh600000-2026.db                # KlineMinute，Time 为源日期时分
```

市场目录和文件名由 SDK `pull.Code` 生成。新库存储股票成交量为股，价格和金额为原币种浮点值；不再写本项目的 Unix 主键、KLM1/KLM2 压缩块。默认首次拉取范围沿用 SDK：未设置 `StartAt` 时最近两年，之后增量更新；原有更早历史仍从旧库读取。

切换运行版本时应停止旧版更新任务，避免两套程序并行维护不同数据集；旧版程序看不到 `source/` 中的新记录，直接回退程序会缺少这些新增行情。

本次不批量转换、移动或覆盖现有行情。查询合并新旧记录：日线按源日期、分钟按源日期时分匹配，重叠时优先新记录，未重叠的旧记录保留。旧分钟文件内部已有的重复顺序保持原有读取口径；被新记录覆盖的同一分钟旧记录一起移出查询结果。日线查询使用日期边界，计算新记录昨收时保留前一条可用日线。

只读查询不会初始化不存在或无格式标记的源目录。损坏的旧库、新库或不兼容格式会返回错误，不把读取失败当作无行情。原有 `kline-compress` 命令只处理旧 `min-kline/`，显式执行时仍可转换旧文件；它不处理新 `source/`。

股票池合并枚举旧日线与新 `source/cn/stock/day/`，保留退市历史代码并去重。注入外部 Store 时，证券池仍须由应用配置或本地数据提供，SDK Store 接口不提供证券枚举。

## 应用与 SDK 的职责

- SDK `pull` 市场单元负责分页拉取、集合竞价、股本回填、分钟覆盖以及源时间落库。本项目不再维护旧日线与分钟库的增量写入实现。
- 应用保留股票范围、CLI/Web 更新锁、每代码/类型的终态重试和页面进度、完整批次标记及估值采集。SDK 整批 `Update()` 没有应用所需的逐代码/类型终态进度回调，因此应用编排直接复用 SDK 的公开拉取单元。
- `PullKlineConfig.Store` 可注入 SDK `pull.Store`；注入资源由调用方关闭。默认更新时创建源时间 SQLite Store，任务结束关闭；不在每个代码上重复打开。
- 源数据完成标记按存储身份、显式代码范围、类型和起始日期隔离，旧 `pull` 标记不跳过新数据集首次拉取。`LastSuccessfulUpdate()` 继续读取完整批次完成时间。任务完成时间属于运行状态，可使用真实 Unix 时间，不是行情源时间。
- 本应用的自动更新日历、默认股票池、估值和回测仍针对 A 股。扩展市场拉取使用 SDK 的 `ExPool` 配置；本应用更新入口未启用该连接，不隐式建立扩展市场连接。

## 回测时间边界

策略仍使用现有 `Kline/Klines`、`time.Time` 和整数手模型。标准市场读取边界显式将股转换为手，将源日期映射到原有日线执行时刻；15:00 只存在于当前标准市场回测视图，不写入源日线表。旧库读取统一使用标准行情约定的固定东八区，不依赖主机 `time.Local`。内存中的 `Kline.Unix` 仅供旧模型兼容，不写入新源时间表。

横截面排名以内存源日期字符串作为键，同一天不因 `time.Location` 指针或偏移不同而查不到；接口仍接收 `time.Time`，取其钟面日期，不按绝对时刻换日。

港美股及期货的源时间可由 SDK Store 原样保存。现有标准市场回测适配器拒绝解释这些扩展源时间，不猜测来源时区、夏令时或夜盘交易日，也不把 A 股 15:00/T+1 规则直接套用过去。跨市场真实时序回测需要另行确认来源口径与交易规则。

MySQL Store 和正式行情导入尚未实现；本次未修改远程数据库或部署服务。
