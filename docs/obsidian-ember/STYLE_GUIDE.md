# 视觉与动效规范

## 视觉方向

紧凑的工具型界面。大面积中性背景承载信息，信号橙表达操作和当前选择，绿色表达成功，琥珀色表达提醒。保留清晰的边界和层次，避免装饰占用主要工作区。

配色精确值以 `tokens.json` / `tokens.css` 为准，来源为已确认的第二版方案。

| 角色 | 深色 | 浅色 |
| --- | --- | --- |
| 页面 `bg` | `#191B1F` | `#ECEEF0` |
| 面板 `surface` | `#222529` | `#F7F8FA` |
| 次级表面 `surface-alt` | `#2C3036` | `#E5E8EB` |
| 舞台 `stage` | `#25282C` | `#DFE3E7` |
| 环境光 `stage-center` | `#393C41` | `#EEF0F2` |
| 主文字 `text` | `#E7E9ED` | `#272C34` |
| 次文字 `muted` | `#A8ADB7` | `#535D6A` |
| 辅助文字 `quiet` | `#9DA4B0` | `#58606C` |
| 边框 `border` | `#373C44` | `#CFD4DA` |
| 操作填充 `accent` | `#ED9968` | `#AB4A21` |
| 强调文字 `accent-text` | `#F3AC81` | `#A9431C` |
| 选中底色 `accent-soft` | `#3D3029` | `#F6E7DD` |

## 字体与尺度

- 字体：Noto Sans CJK SC → PingFang SC → Microsoft YaHei → sans-serif；包内不附带字体文件或字体请求。
- 默认基础字号 13px，正文推荐 12–14px；说明文字 11px。目标项目可在 `.oe-theme` 覆盖 `--oe-font-size`。
- 统一间距：4、8、12、16、20、24、32px。面板间距 12px，常用内边距 20px。
- 圆角：面板 10px；控件 6px；状态标签 3px。
- 参考布局：导航 88px，顶部栏 70px，辅助侧板 300px，宽屏可用 332px。窄屏改为单列；不要强行压缩主要内容。
- 每页一个 `h1`，主操作靠近工作区顶部。详情用弹窗或覆盖浮层，避免展开内容推移主工作区。

## 通用立体效果

1. 悬停透视：1000px 透视、最大约 6° 倾斜；内容层 `translateZ(18px)`。鼠标位置控制表面暖光。触摸设备保留静态外观。
2. 层叠表面：后方两层分别偏移 7px / 14px，并降低透明度；适用于卡片和展示面板。
3. 视图景深：旧画面缩小至 0.89 倍并淡出；新画面由 1.08 倍、轻微 X 轴透视进入。返回方向使用反向比例。
4. Three.js：环境反射、主光、暖色轮廓光、冷色补光和 PCF 柔和阴影。材质为真实 PBR 参数，所有几何内容由使用方提供。

不要给包含 `position:fixed` 浮层的公共容器添加透视或 transform，否则可能改变浮层定位。将立体效果用于独立表面；模态弹窗保持原生顶层。

## 动画参数

| 动作 | 时间 | 用途 |
| --- | --- | --- |
| 悬停 / 按钮 | 180–380ms | 轻微反馈，按下缩放 0.97 |
| 弹窗进入 | 380ms | 淡入、14px 位移、0.97 比例与约 5° 透视 |
| 内容进入 | 700ms | 淡入、12px 向上归位 |
| 景深切换 | 总长约 700ms | 主面板与侧板协调过渡 |
| 旧主面板退出 | 300ms | 后退、淡出 |
| 新主面板进入 | 640ms，延迟 60ms | 轻微透视展开 |
| 新侧板进入 | 520ms，延迟 110ms | 横移 22px 并淡入 |

进入缓动：`cubic-bezier(.16,1,.3,1)`；退出缓动：`cubic-bezier(.4,0,1,1)`。

切换动画不改变业务状态含义，不模拟真实数值；减少动态效果时立即更新内容。权限清理、用户主动停止及资源释放不能等待动画。

## Three.js 参数边界

`three-presets.json` 提供的是约十个单位大小的局部展示环境。场景尺寸变化后，须调整相机距离、`near/far`、阴影相机范围及环境曝光。`three-scene.js` 默认不自动旋转、不自动创建对象，也不连接任何数据。

CSS 动效在不使用 WebGL 的项目中同样可用。保留主要内容、操作和键盘焦点；空间效果用于交互反馈，不代替信息。
