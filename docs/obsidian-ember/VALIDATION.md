# 导出验证

2026-11-17，在独立的本地静态页面与 Chromium 中验证，不连接业务服务。

- 深浅主题 CSS 变量与导出 JSON 逐项一致。
- 主文字、次文字、辅助文字、强调链接及主按钮文字的指定组合对比度均超过 4.5:1；其中最低约 5.39:1。这不代表所有自定义颜色组合都通过检查。
- CSS 立体悬停、关闭动效后的立即复位、景深切换、快速反向与更新异常处理通过。
- 弹窗打开、Esc 关闭、原生 View Transition 不可用时直接切换通过。
- 系统减少动态效果可在运行时生效；内容不滞留在隐藏状态。
- 1440px、390px、320px 页面没有横向溢出；深浅主题及窄屏截图已检查。
- 可选 Three.js 模块经过真实 WebGL 渲染：连续动画、静态停止绘制、相机聚焦、通用分层与快速反向、中途减少动态效果、重复销毁与几何/材质释放通过。
- Python 预览启动器可选择空闲回环端口，并返回独立示例页面。
- 核心示例没有第三方资源或业务 API 请求；目录没有三维模型、贴图、机器人或园区页面。

浏览器回归脚本在原项目的 `frontend/tests/visualKit.browser.mjs`。未把测试夹具、浏览器运行库或任何测试几何资源打入此包；WebGL 检查所用简单几何仅在测试进程中创建。

本次覆盖 Chromium；其他浏览器与目标项目的实际组件组合应在接入时再验证。
